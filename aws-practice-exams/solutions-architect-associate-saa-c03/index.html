Sample question 1 Design High-Performing Architectures

A company receives 2 TB of CSV files in Amazon S3 each night. A serverless job must convert them to Apache Parquet with custom Spark transformations, process only new files each night, and require no cluster management. Which solution meets these requirements?

  1. A permanent Amazon EMR cluster that runs a Spark job on a schedule
  2. An AWS Glue ETL job with job bookmarks enabled that writes Parquet to Amazon S3
  3. An AWS Lambda function triggered by each new object that converts the file to Parquet
  4. Amazon Redshift COPY commands followed by UNLOAD to Parquet in Amazon S3
Show the answer and explanation

Correct answer: B.

Option B is correct because AWS Glue runs Spark ETL jobs serverlessly, and job bookmarks track processed data so that each run handles only new files. Option A is incorrect because a permanent EMR cluster must be managed and paid for continuously. Option C is incorrect because Lambda has a 15-minute limit and limited memory, which is a poor fit for multi-gigabyte files and Spark transformations. Option D is incorrect because it requires a Redshift cluster and is not designed for custom Spark transformations. Takeaway: Glue is the serverless option for Spark-based ETL.

Sample question 2 Design Secure Architectures

A web application on Amazon EC2 has a server-side request forgery (SSRF) vulnerability that could let an attacker read the instance role credentials from the instance metadata service. The company wants to reduce this risk without changing the instance role. Which TWO actions should a solutions architect take? (Select TWO) (Choose 2.)

  1. Set the instance metadata option HttpTokens to required so that only IMDSv2 session-token requests are accepted
  2. Turn on detailed monitoring for the instances so that metadata requests are logged in CloudWatch
  3. Set the metadata response hop limit to 1 for instances that do not run containers that need metadata access
  4. Add an outbound security group rule that blocks the link-local address 169.254.169.254
  5. Move the role credentials into the instance user data so that they are not served by the metadata service
Show the answer and explanation

Correct answer: A and C.

Options A and C are correct. IMDSv2 requires a session token obtained with a PUT request, which typical SSRF attacks cannot perform, and a hop limit of 1 keeps the token response from being forwarded beyond the instance. Option B is incorrect because detailed monitoring provides metrics at one-minute intervals and does not log or block metadata requests. Option D is incorrect because security groups do not filter traffic to the instance metadata service. Option E is incorrect because user data is also readable through the metadata service and would not protect credentials. Takeaway: enforce IMDSv2 to mitigate credential theft through SSRF.

Sample question 3 Design Resilient Architectures

A company needs hybrid connectivity to AWS for a critical workload. The design must tolerate the failure of a single Direct Connect device, a single connection, and an entire Direct Connect location. Which architecture meets these requirements?

  1. One Direct Connect location with two connections that terminate on separate devices
  2. One Direct Connect connection with an AWS Site-to-Site VPN as a backup
  3. Two Direct Connect connections at the same location that share one customer router
  4. Two Direct Connect locations, each with two connections that terminate on separate devices
Show the answer and explanation

Correct answer: D.

Option D is correct because the maximum resiliency model uses two locations with redundant connections and devices at each, so no single device, connection, or location failure interrupts connectivity. Option A is incorrect because both connections are at one location, so a location failure disconnects the workload. Option B is incorrect because the VPN backup uses the internet and gives different performance, and the Direct Connect itself has single points of failure. Option C is incorrect because the shared router and same location remain single points of failure. Takeaway: use multiple locations and devices for maximum Direct Connect resiliency.

Sample question 4 Design Cost-Optimized Architectures

An application's traffic to an Amazon DynamoDB table follows a steady, predictable daily pattern with gradual increases. The table uses on-demand capacity mode and the request charges are high. The company wants to reduce cost while avoiding throttling. Which solution meets these requirements?

  1. Switch the table to provisioned capacity mode with auto scaling based on target utilization
  2. Switch the table to provisioned capacity mode with a fixed capacity set to the daily peak
  3. Keep on-demand mode and change the table class to Standard-Infrequent Access
  4. Keep on-demand mode and enable DynamoDB Accelerator (DAX) to reduce the table's write charges
Show the answer and explanation

Correct answer: A.

Option A is correct because predictable traffic that changes gradually suits provisioned capacity with auto scaling, which costs less per request than on-demand while adjusting to the daily pattern. Option B is incorrect because a fixed peak-level capacity wastes money during the rest of the day. Option C is incorrect because the Standard-IA table class raises request prices and helps only tables where storage is the dominant cost. Option D is incorrect because DAX caches reads and does not reduce write charges. Takeaway: on-demand suits unpredictable traffic, and provisioned with auto scaling suits predictable traffic.

Sample question 5 Design High-Performing Architectures

A company hosts a custom TCP-based trading protocol on Amazon EC2 instances. Clients must connect to fixed IP addresses that they have allow-listed in their firewalls, and the load balancer must handle millions of connections per second with very low latency. Which load balancer meets these requirements?

  1. A Network Load Balancer with an Elastic IP address per Availability Zone
  2. A Gateway Load Balancer with a target group of virtual appliances
  3. An Application Load Balancer with a static DNS name for the clients
  4. A Classic Load Balancer with sticky sessions enabled on the TCP listener
Show the answer and explanation

Correct answer: A.

Option A is correct because a Network Load Balancer operates at layer 4, handles millions of connections with very low latency, and supports Elastic IP addresses for static addressing. Option B is incorrect because a Gateway Load Balancer inserts network appliances in the traffic path and is not a general endpoint for client connections. Option C is incorrect because an Application Load Balancer works at layer 7 for HTTP protocols and does not provide static IP addresses. Option D is incorrect because a Classic Load Balancer is a legacy option without static IP support or this scale. Takeaway: use NLB for non-HTTP TCP or UDP traffic that needs static IPs.

Sample question 6 Design Secure Architectures

Amazon GuardDuty reports that an Amazon EC2 instance is communicating with a known cryptocurrency mining pool. The security team wants the instance to be automatically isolated from the network within minutes of such a finding, with the LEAST custom infrastructure. Which solution meets these requirements?

  1. Turn on a GuardDuty setting that automatically stops any instance that has a high-severity finding, and review it later
  2. Create an EventBridge rule for the finding type that invokes a Lambda function to attach an isolation security group to the instance
  3. Create a CloudWatch alarm on CPU utilization that sends an email to the administrators, who then review the instance
  4. Enable Amazon Inspector with a rules package that quarantines instances that communicate with known malicious hosts automatically on the instance
Show the answer and explanation

Correct answer: B.

Option B is correct because GuardDuty publishes findings to EventBridge, and a rule can trigger a Lambda function or Systems Manager Automation runbook that applies an isolation security group. Option A is incorrect because GuardDuty detects threats and does not include an automatic stop action. Option C is incorrect because a CPU alarm with email is manual and does not isolate the instance. Option D is incorrect because Inspector assesses vulnerabilities and network exposure and does not quarantine instances. Takeaway: automate responses by routing GuardDuty findings through EventBridge.

Sample question 7 Design Resilient Architectures

An Amazon Aurora cluster has one writer and three Aurora Replicas of different sizes. One replica is the same large instance class as the writer, and the other two are small replicas used for light reporting. If the writer fails, the company wants Aurora to promote the large replica so that performance stays the same. Which configuration meets this requirement?

  1. Enable Aurora Auto Scaling for the replicas so that the largest replica is always promoted
  2. Configure a Multi-AZ standby instance for the cluster and set it to the same class as the writer
  3. Assign the large replica the highest failover priority (tier 0) and assign the small replicas lower priorities
  4. Create a custom cluster endpoint that contains only the large replica and connect the application to it, so that failover always chooses that replica
Show the answer and explanation

Correct answer: C.

Option C is correct because Aurora promotes the replica with the best failover priority tier (0 is highest) and, among equal tiers, prefers the largest instance, so setting tier 0 on the large replica makes it the promotion target. Option A is incorrect because Aurora Auto Scaling adds or removes replicas based on load and does not control promotion. Option B is incorrect because Aurora clusters do not have a separate Multi-AZ standby instance; replicas serve as failover targets. Option D is incorrect because a custom endpoint routes client connections and does not decide which replica is promoted. Takeaway: use failover priority tiers to control promotion order.

Sample question 8 Design Cost-Optimized Architectures

A company will run a steady set of Amazon EC2 instances for three years, but expects to change instance families as new generations are released. The company wants a reserved discount and needs the ability to exchange the reservation for a different family. The company is not evaluating Savings Plans. Which option meets these requirements?

  1. Spot Instances with a persistent request
  2. On-Demand Instances with an On-Demand Capacity Reservation
  3. Standard Reserved Instances with a three-year term
  4. Convertible Reserved Instances with a three-year term
Show the answer and explanation

Correct answer: D.

Option D is correct because Convertible Reserved Instances can be exchanged for other Convertible Reserved Instances with different instance families, sizes, or operating systems, at a somewhat smaller discount than Standard. Option A is incorrect because Spot capacity can be interrupted and is not a reserved discount. Option B is incorrect because a Capacity Reservation reserves capacity and gives no pricing discount. Option C is incorrect because Standard Reserved Instances cannot be exchanged for a different instance family. Takeaway: choose Convertible RIs when flexibility matters more than the maximum discount.
